# ✅ ЭТАП 2 — Данные и доменная модель
## 2.1 Domain модели

- **Transaction**: Id, Amount, Date, Type, CategoryId, AccountId, Note, Tags

- **Category**: Id, Name, Type (Income/Expense), Color, Icon

- **Account**: Id, Name, Currency, InitialBalance

- **Budget**: Id, CategoryId, Period, LimitAmount

- **Goal**: Id, Name, TargetAmount, CurrentAmount, Deadline

- **Enums**: TransactionType (Income/Expense/Transfer), PeriodType (Monthly/Yearly)

## 2.2 EF Core + SQLite

- Создать **AppDbContext** и настроить конфигурации (Fluent API)

- Настроить автоматические миграции при запуске

- Реализовать **Seed данных**: базовый набор категорий и счета по умолчанию

- Настроить динамический путь к базе в папке `AppData/BudgetTracker`

## 2.3 Репозитории и слой данных

- Создать интерфейсы и реализации: `ITransactionRepository`, `ICategoryRepository`, `IAccountRepository`

- Реализовать паттерн **Unit of Work** (или аналогичный сервис управления транзакциями)

- Логика автоматического обновления баланса счета при совершении операций

**Definition of Done этапа**: база данных создается миграцией, заполняется начальными данными, репозитории протестированы и работают.
